has_filterable_chems
(/mob/living/carbon/target, /obj/item/blood_filter/bloodfilter)

Checks if the mob contains chems we can filter

If the blood filter's blacklist is not empty this checks that the mob contains any chems not in the blacklist Otherwise, if the blacklist is empty this always returns true

Arguments:

  • target - The mob to check the chems of
  • bloodfilter - The blood filter to check the blacklist of
